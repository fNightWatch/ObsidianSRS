# UI upgrade notes

## Что изменено

- Интерфейс разбит по вкладкам: **Обзор**, **Ревью**, **Отчёт**, **Активность**.
- Верхняя панель стала рабочей: основные действия доступны сразу и не разбросаны по экрану.
- Добавлены учебные KPI-карточки:
  - критичные заметки,
  - заметки высокого приоритета,
  - средняя сложность,
  - следующая заметка для повторения.
- Добавлена отдельная очередь **«Сегодня в фокусе»** с быстрым переходом в ревью.
- На вкладке **Ревью** появился предпросмотр заметки и быстрые значения сложности.
- На вкладке **Отчёт** добавлены:
  - поиск по имени заметки,
  - фильтр по band,
  - лимит отображения,
  - сортировка по клику на заголовки,
  - правый preview-pane с краткой рекомендацией.
- Добавлен copy-path workflow, чтобы быстрее прыгать к заметке в других инструментах.
- Добавлены горячие клавиши для быстрых действий.
- Нижний журнал вынесен в отдельную вкладку, чтобы он не давил на основной экран.
- Фоновые операции сохраняются, а индикатор прогресса делает состояние приложения понятнее.

## Что уже даёт прирост в продуктивности

- Меньше переключений внимания: сначала смотришь фокус, потом сразу переходишь в ревью.
- Меньше поиска вручную: заметка подставляется из очереди по двойному клику.
- Меньше контекстного шума: отчёт, лог и ручное ревью не смешаны на одном полотне.
- Меньше решения «что учить сейчас»: карточка `Следующая заметка` и фокус-очередь это решают.
- Меньше открываний Obsidian вслепую: есть встроенный preview и мета-информация.

## Что логично добавить следующим этапом

### 1. Режим учебной сессии
Отдельный экран на 10–20 минут:
- взять top-N заметок,
- идти по ним по одной,
- в конце показывать короткую сводку по закрытой сессии.

### 2. Тематические очереди
Группировка по папкам и тегам:
- математика,
- история,
- языки,
- экзамен X.

Это помогает делать не только «общую» очередь, но и очереди под конкретный предмет.

### 3. Daily / weekly planning
Автогенерация:
- «минимум на сегодня»,
- «идеальный план на 30 минут»,
- «что критично до конца недели».

### 4. Обратная связь по нагрузке
Показывать:
- сколько заметок уходит в красную зону,
- где перегруз по сложности,
- какие темы чаще всего проваливаются.

### 5. Быстрое открытие заметки в Obsidian
Кнопка вида **Открыть заметку**, чтобы переходить в источник без копирования пути.

### 6. История и аналитика прогресса
Графики:
- review в день,
- средняя сложность по неделям,
- доля красных заметок,
- стабилизация базы знаний.

### 7. Экзаменационный режим
Временное повышение срочности для заметок из конкретной темы или папки перед контрольной/экзаменом.

## Новый слой: Obsidian bridge

### Что теперь появляется прямо внутри vault
- `_SRS Queue.md` — автогенерируемая приоритетная очередь по заметкам.
- `_SRS Commands.md` — markdown-файл для простых команд, которые приложение автоматически подбирает и исполняет.

### Что это меняет в практике
- можно работать почти полностью из Obsidian,
- очередь всегда лежит рядом с заметками,
- команды не требуют открытия отдельного CLI,
- появляется плавный путь к будущему Obsidian-плагину.

### Команды
Поддерживаются команды:
- `обновить` / `update`,
- `сканировать` / `scan`,
- `синхронизировать` / `sync`,
- `отчёт` / `report`,
- `очередь` / `queue`,
- `ревью 7 [[folder/note]]`,
- `review [[folder/note]] 7`.
